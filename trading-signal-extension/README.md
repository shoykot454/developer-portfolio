# Trade Signal Lab: Chrome Extension

টেকনিক্যাল অ্যানালাইসিসের ৯টা ফ্যাক্টর মিলিয়ে **BUY / SELL / WAIT** সিগন্যাল দেয়। নিজের সিগন্যালের ফলাফল (TP লেগেছে নাকি SL) দেখে কোন ফ্যাক্টরকে কতটা গুরুত্ব দেবে, তা **নিজে নিজে শেখে**।

> ⚠️ এটা শেখার টুল, টাকা বানানোর মেশিন না। কোনো সিগন্যাল নিশ্চিত না। আগে Demo-তে পরীক্ষা করুন।

## ইনস্টল
1. এই `trading-signal-extension` ফোল্ডারটা কম্পিউটারে রাখুন (ZIP হলে আনজিপ করুন)।
2. Chrome-এ `chrome://extensions` খুলুন।
3. ডানে উপরের **Developer mode** চালু করুন।
4. **Load unpacked** চেপে এই ফোল্ডারটা বেছে নিন।
5. টুলবারে 📈 আইকন পিন করে নিন।

## কী কী করে
| ট্যাব | কাজ |
|---|---|
| **সিগন্যাল** | পেয়ার (যেমন BTCUSDT) আর টাইমফ্রেম দিয়ে অ্যানালাইসিস। দেখায় Entry, Stop-loss, Take-profit, পজিশন সাইজ, আর প্রতিটা ফ্যাক্টর কেন কী বলছে |
| **শেখা** | ফ্যাক্টরের ওজন, Win rate। "ট্রেনিং শুরু" চাপলে শেষ ১০০০ ক্যান্ডেলে backtest চালিয়ে শেখে |
| **জার্নাল** | সব BUY/SELL সিগন্যাল আর তার ফলাফল (TP ✓ / SL ✗) |
| **সেটিংস** | Watchlist, ব্যালেন্স, ঝুঁকি %, R:R, অটো-স্ক্যান + নোটিফিকেশন |

## ৯টা ফ্যাক্টর
বড় টাইমফ্রেমের ট্রেন্ড (EMA50/200) · মার্কেট স্ট্রাকচার (HH/HL) · EMA 9/21 · MACD · RSI · Bollinger Bands · সাপোর্ট/রেজিস্ট্যান্স · ক্যান্ডেলস্টিক প্যাটার্ন (Engulfing, Hammer, Shooting Star) · ভলিউম

প্রতিটা ফ্যাক্টর −১ থেকে +১ ভোট দেয়। `score = Σ(ভোট × ওজন) / Σ(ওজন)`। score থ্রেশহোল্ডের উপরে হলে BUY, নিচে হলে SELL। বড় ট্রেন্ডের বিপরীতে গেলে আরও শক্ত সিগন্যাল লাগে।
Stop-loss = ১.৫ × ATR, Take-profit = Stop-loss দূরত্ব × R:R।

## কীভাবে শেখে
প্রতিটা সিগন্যালের পরে যদি TP লাগে, তাহলে যে ফ্যাক্টরগুলো সঠিক দিকে ভোট দিয়েছিল তাদের ওজন বাড়ে। SL লাগলে কমে (ওজন ০.১ থেকে ৩-এর মধ্যে থাকে)।
Backtest-এ প্রতিটা ক্যান্ডেলে শুধু তখন পর্যন্ত জানা ডেটা ব্যবহার হয় (look-ahead নেই)। একদম random ডেটায় পরীক্ষা করলে win rate ~৩১% আসে, যা ১:২ R:R-এ প্রত্যাশিত ~৩৩%-এর কাছাকাছি।

## সীমাবদ্ধতা
- ডেটা আসে Binance-এর পাবলিক API থেকে (ক্রিপ্টো পেয়ার: BTCUSDT, ETHUSDT, PAXGUSDT (সোনা), EURUSDT ইত্যাদি)। কোনো API key লাগে না।
- **Quotex / IQ Option-এর OTC চার্ট এখানে পাওয়া যায় না।** ওই দাম প্ল্যাটফর্মের নিজের তৈরি, আসল মার্কেটের সাথে মেলে না।
- Backtest-এ fee/spread ধরা হয়নি। ভালো backtest মানেই ভবিষ্যতে লাভ না (overfitting)।
- Win rate-কে R:R-এর সাথে মিলিয়ে দেখুন: ১:২ R:R-এ লাভে থাকতে ৩৩%-এর বেশি জিততে হবে।
