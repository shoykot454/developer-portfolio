# YouTube & Facebook Video Downloader

একটা YouTube চ্যানেলের লিঙ্ক (বা `@handle`) দিন → চ্যানেলের সব **Shorts** অথবা সব **লম্বা ভিডিও** দেখাবে →
একটা একটা করে, অথবা সিলেক্ট করে সবগুলো একসাথে ডাউনলোড করুন।

## ফিচার
- উপরে **YouTube / Facebook** বাছাই
- **Facebook**: দুটো ট্যাব — **🎞️ Reels** আর **🎬 ভিডিও**
  - এক বা অনেকগুলো লিঙ্ক একসাথে পেস্ট করুন (প্রতি লাইনে একটা; অন্য লেখার মধ্যে থাকলেও খুঁজে নেয়)
  - চলে: `facebook.com/reel/…`, `facebook.com/<page>/videos/…`, `facebook.com/watch?v=…`, `fb.watch/…` — শুধু পাবলিক ভিডিও
  - পুরো পেজের সব লিঙ্ক তুলতে সাইটের "📋 FB লিঙ্ক কপি" বুকমার্ক টুল ব্যবহার করুন (সাইটে ধাপগুলো লেখা আছে)
  - Reels যায় `Downloads\Facebook Reels\<পেজ>`, ভিডিও যায় `Downloads\Facebook Videos\<পেজ>`
  - ফেসবুক নিজে পুরো পেজের লিস্ট দেয় না, তাই YouTube-এর মতো শুধু পেজের লিঙ্ক দিয়ে সব আনা যায় না
- **একটা ভিডিওর লিঙ্ক** দিলে (`/shorts/…`, `watch?v=…`, `youtu.be/…`) শুধু সেটাই নামানো যায় — Short নাকি লম্বা ভিডিও, নিজে চিনে ঠিক ফোল্ডারে রাখে
- উপরে দুটো ট্যাব: **📱 Shorts** আর **🎬 লম্বা ভিডিও** — যেটা চান বেছে নিন
  - Shorts সেভ হয় `Downloads\YouTube Shorts\<চ্যানেল>` ফোল্ডারে
  - লম্বা ভিডিও সেভ হয় `Downloads\YouTube Videos\<চ্যানেল>` ফোল্ডারে
  - কোয়ালিটি: Best / 1080p / 720p / 480p / শুধু অডিও (লম্বা ভিডিওতে ডিফল্ট 1080p, কারণ 4K অনেক বড় হয়)
- চ্যানেল লিঙ্ক চেনে: `youtube.com/@name`, `/channel/UC…`, `/c/name`, `/user/name`, শুধু `@name`, অথবা একটা `/shorts/…` লিঙ্ক
- থাম্বনেইল, টাইটেল, ভিউ, ডিউরেশনসহ সব Shorts-এর গ্রিড
- সিলেক্ট/আনসিলেক্ট, কোয়ালিটি বাছাই (Best / 720p / 480p / শুধু অডিও)
- একসাথে হাজারখানেক Shorts ডাউনলোড (৩টা করে প্যারালাল), লাইভ প্রোগ্রেস; কোনোটা ফেল করলে বাকিগুলো চলতে থাকে
- ভিডিও সরাসরি `Downloads\YouTube Shorts\<চ্যানেলের নাম>` ফোল্ডারে সেভ হয়; চাইলে ZIP হিসেবেও নেওয়া যায়
- **একই ভিডিও কখনো দুবার নামে না:** প্রতিটা ডাউনলোড `YouTube Shorts\.downloaded.json`-এ মনে রাখা হয় (অ্যাপ বন্ধ করলেও মনে থাকে)।
  লিস্টে আগে নামানো Shorts "✓ আগে নামানো" দেখায় আর আনচেক থাকে — ডাউনলোড চাপলে শুধু নতুনগুলো নামে।
  চ্যানেলের নাম বদলালেও, বা একই ভিডিও একসাথে দুবার চাপলেও, একবারই নামে।
- মাঝপথে নেট/কম্পিউটার বন্ধ হলে আবার চালালে বাকিগুলো নামায়; আধা-নামানো ফাইল যেখানে থেমেছিল সেখান থেকে চলে
- মোবাইলে চলে

## সবচেয়ে সহজে চালানো (Windows)
1. **`Create Desktop Shortcut.bat`**-এ একবার ডাবল ক্লিক করুন — Desktop-এ **Video Downloader** আইকন তৈরি হবে।
2. এরপর থেকে শুধু Desktop-এর **Video Downloader** আইকনে ডাবল ক্লিক করুন — সাইট চালু হবে আর ব্রাউজার নিজে খুলে যাবে।

`Start Downloader.bat` নিজে থেকে: Python খোঁজে, প্রথমবার দরকারি প্যাকেজ ইনস্টল করে, প্রতিবার yt-dlp আপডেট করে,
ffmpeg না থাকলে সতর্ক করে। সাইট আগে থেকে চালু থাকলে আবার চালু না করে শুধু ব্রাউজার খোলে।

## চালানোর নিয়ম
দরকার: **Python 3.9+**, **ffmpeg** (ভিডিও আর অডিও জোড়া লাগাতে লাগে) আর **Deno**
(YouTube-এর পুরো কোয়ালিটির জন্য yt-dlp-এর লাগে; `Start Downloader.bat` নিজে ইনস্টল করে, হাতে করতে চাইলে `winget install DenoLand.Deno`)।

```bash
cd youtube-shorts-downloader
pip install -r requirements.txt
python app.py
```
তারপর ব্রাউজারে খুলুন: http://localhost:5000

ffmpeg ইনস্টল: Windows → `winget install ffmpeg`, macOS → `brew install ffmpeg`, Ubuntu → `sudo apt install ffmpeg`

## সেটিংস (environment variables)
| Variable | Default | কাজ |
|---|---|---|
| `PORT` | 5000 | সার্ভার পোর্ট |
| `MAX_SHORTS` | 5000 | একটা চ্যানেল থেকে সর্বোচ্চ কতগুলো Shorts লিস্ট হবে |
| `MAX_PER_JOB` | 5000 | একবারে সর্বোচ্চ কতগুলো ডাউনলোড |
| `CONCURRENCY` | 3 | একসাথে কতগুলো ভিডিও নামবে (বেশি দিলে YouTube ব্লক করতে পারে) |
| `SAVE_DIR` | `~/Downloads/YouTube Shorts` | Shorts কোথায় সেভ হবে |
| `VIDEOS_DIR` | `~/Downloads/YouTube Videos` | লম্বা ভিডিও কোথায় সেভ হবে |
| `JOB_TTL_SECONDS` | 21600 | কতক্ষণ পর পুরনো জবের অস্থায়ী ZIP মুছে যাবে |
| `DOWNLOAD_ROOT` | system temp | অস্থায়ী ফাইল/ZIP কোথায় রাখা হবে |

## নোট
- YouTube মাঝে মাঝে নিয়ম বদলায়; ডাউনলোড বন্ধ হয়ে গেলে `pip install -U yt-dlp` দিয়ে আপডেট করুন।
- এটা ব্যক্তিগত/লোকাল ব্যবহারের জন্য বানানো। পাবলিক সার্ভারে দিলে YouTube সার্ভারের IP ব্লক করতে পারে, আর রেট-লিমিট/লগইন যোগ করা উচিত।
- শুধু নিজের কনটেন্ট বা যেগুলোর অনুমতি আছে সেগুলো ডাউনলোড করুন — কপিরাইট ও YouTube Terms মেনে চলুন।
